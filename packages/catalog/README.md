# Catalog (`packages/catalog`)

## Overview

Package `@storagemaxxing/catalog` provides storage system and bin specification schemas, built-in vendor catalogs, and catalog lookup helpers.

## Subdirectories & boundaries

- `src`: [./src/README.md](./src/README.md) — Part/bin schemas, built-in catalogs, and lookup helpers.
- `test`: [./test/README.md](./test/README.md) — Golden-path catalog resolution and unknown-ID contract tests.
