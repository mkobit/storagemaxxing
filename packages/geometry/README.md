# Geometry (`packages/geometry`)

## Overview

Package `@storagemaxxing/geometry` groups foundational geometric primitives, branded length units (`Inches` and `Millimeters`), fraction formatting, oblique projection, and `bun:test` unit matchers.

## Subdirectories & boundaries

- `src`: [./src/README.md](./src/README.md) — Core geometry primitives, unit conversions, fraction utilities, and test matchers.
