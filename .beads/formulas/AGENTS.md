# Beads Formulas Standard

All formulas in this directory MUST be written in **TOML** format.

- **File extension**: `.formula.toml`
- **Rationale**: TOML is more human-readable, supports comments, and is the preferred configuration format for this repository.
- **Enforcement**: Any agent creating or updating a formula MUST use TOML. JSON formulas are deprecated and should be converted when encountered.
